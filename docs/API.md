## `scfsim.network`

Generation of layered supply chain finance networks.

### `generate_network(cfg: 'NetworkConfig', rng: 'Optional[np.random.Generator]' = None) -> 'nx.DiGraph'`

Build a random layered SCF network from ``cfg``.

### `core_node(g: 'nx.DiGraph') -> 'str'`

Name of the single ``kind == "core"`` node of ``g``.

### `validate_network(g: 'nx.DiGraph', tol: 'float' = 1e-06) -> 'None'`

Raise ``ValueError`` if ``g`` violates the attribute convention.

### `network_from_edges(edges, core: 'str', banks=1) -> 'nx.DiGraph'`

Build a compliant network from ``(supplier, buyer, share)`` triples.

## `scfsim.simulation`

## `scfsim.invariants`

Accounting identities and state invariants.

### `class InvariantViolation`

Raised when the model's book-keeping is internally inconsistent.

### `check_invariants(firms: "Dict[str, 'FirmState']", banks: "Dict[int, 'BankState']", cfg: "'SimulationConfig'", t: 'int' = -1, core_name: 'str' = 'core-0') -> 'None'`

Verify every accounting identity and domain bound. Raises on failure.

### `network_invariants(g) -> 'List[str]'`

Structural properties a valid SCF network must satisfy.

## `scfsim.economics`

Economic invariants: properties the model must satisfy to be *right*, not merely self-consistent.

### `class EconomicViolation`

Raised when the model's behaviour contradicts its own economics.

### `check_economics(firms: "Dict[str, 'FirmState']", banks: "Dict[int, 'BankState']", cfg: "'SimulationConfig'", orders: 'Dict[str, float] | None' = None, books: 'Dict[str, float] | None' = None, t: 'int' = -1, core_name: 'str' = 'core-0') -> 'None'`

Verify the structural economic properties. Raises on failure.

### `check_drawing(firm: "'FirmState'", eligible: 'float', tightening: 'float', cfg: "'SimulationConfig'", proceeds: "'float | None'" = None) -> 'None'`

A new drawing must be supported by collateral at the time it is made.

### `comparative_statics() -> 'Dict[str, int]'`

Return the signed predictions, keyed by configuration path.

## `scfsim.metamorphic`

Metamorphic relations: verification without a known answer.

### `scaled(cfg: 'SimulationConfig', factor: 'float') -> 'SimulationConfig'`

Return ``cfg`` with the monetary unit multiplied by ``factor``.

### `relabelled(g: 'nx.DiGraph', rng) -> 'Tuple[nx.DiGraph, Dict[str, str]]'`

Permute firm names within each tier; return the graph and the mapping.

### `truncated(cfg: 'SimulationConfig', n_periods: 'int') -> 'SimulationConfig'`

Return ``cfg`` stopped after ``n_periods`` periods.

### `outcome_signature(result, places: 'int' = 9) -> 'tuple'`

A comparable fingerprint of a run's aggregate trajectory.

## `scfsim.benchmark`

Analytical benchmarks used to verify the simulation engine.

### `supply_reachable_set(g: 'nx.DiGraph', seeds: 'Iterable[str]') -> 'Set[str]'`

Firms reachable from ``seeds`` along trade edges (supplier -> buyer).

### `demand_reachable_set(g: 'nx.DiGraph', seeds: 'Iterable[str]') -> 'Set[str]'`

Firms that can reach ``seeds`` along trade edges (buyer -> supplier).

### `attributable_defaults(treated, control) -> 'Set[str]'`

Defaults present in the seeded run but not in the matched control.

### `isolated_channel_configs(base: 'SimulationConfig') -> 'Dict[str, SimulationConfig]'`

Ablation configs switching the channels on one at a time.

### `leave_one_out_configs(base: 'SimulationConfig') -> 'Dict[str, SimulationConfig]'`

Ablation configs switching the channels off one at a time.

## `scfsim.sweep`

Parameter sweeps for sensitivity analysis.

### `set_by_path(cfg: 'SimulationConfig', path: 'str', value) -> 'None'`

Set ``cfg`` attribute addressed by a dotted path, e.g. ``"scenario.bc_fraud_prob"`` or ``"firm.initial_cash_ratio"``.

### `sweep(config: 'SimulationConfig', path: 'str', values: 'Sequence', n_runs: 'int' = 50, base_seed: 'int' = 0, n_jobs: 'int' = 1, network=None) -> 'List[Dict]'`

Run one matched Monte-Carlo batch per value of ``path``.

### `ablation(configs: 'Dict[str, SimulationConfig]', n_runs: 'int' = 50, base_seed: 'int' = 0, n_jobs: 'int' = 1, network=None) -> 'Dict[str, Dict]'`

Run a matched batch for every named configuration variant.

### `grid_sweep(config: 'SimulationConfig', grid: 'Dict[str, Sequence]', n_runs: 'int' = 50, base_seed: 'int' = 0, max_simulations: 'int' = 20000, progress: 'bool' = False, n_jobs: 'int' = 1, network=None) -> 'List[Dict]'`

Sweep several configuration paths jointly over their Cartesian product.

### `channel_decomposition(isolated: 'Dict[str, Dict]', loo: 'Dict[str, Dict]', metric: 'str' = 'mean_cascade_size', channels: 'Sequence[str]' = ('counterparty', 'supply', 'demand', 'credit_crunch')) -> 'Dict'`

Decompose a coupled outcome into per-channel and interaction terms.
